## 核心贡献

本文是 DDGR [CRYPTO 2020] 的**直接续作**，从几何（椭球）视角重新审视 LWE with Hints 的安全估计。引入了两种新提示类型（不等式提示、组合提示），并使用 Löwner-John 椭球和椭球融合技术统一处理所有提示的集成。

### 四大贡献

1. **几何框架**: 将 DBDD 实例表示为椭球，提示集成变为椭球几何运算
2. **不等式提示**: 建模解密失败信息——⟨v, s⟩ ≤ l（单向约束）
3. **组合提示**: 融合多个信息源（SCA + 解密失败）的椭球融合
4. **Failure Boosting 几何类比**: 将解密失败加速搜索映射为椭球缩放

## 几何框架

### 椭球表示
- DBDD 实例 = 中心 c + 畸变矩阵 B
- 几何表示: 椭球 E = { x : (x-c)^T · B^{-1} · (x-c) ≤ 1 }
- 提示集成 = 椭球与约束区域的**交叉**

### 提示的几何运算

| 提示类型 | 几何运算 | 数学工具 |
|---------|---------|---------|
| 完美提示 | 椭球 ∩ 超平面 | Löwner-John 椭球近似 |
| 模提示 | 椭球 ∩ 平行超平面族 | 多次超平面交叉 |
| 不等式提示 | 椭球 ∩ 半空间 | Lötwner-John 椭球 |
| 近似提示 | 椭球 ∩ 高斯模糊超平面 | 椭球缩放+交叉 |
| 组合提示 | 两个椭球的**融合** | 椭球融合(Minkowski-like) |
| 短向量提示 | 椭球 ∩ 格陪集 | 格关系投影 |

### Löwner-John 椭球
- **问题**: 椭球与半空间交叉后不再是椭球
- **解决**: 用最小体积包含椭球（Löwner-John 椭球）近似
- **代价**: 每次近似丢失少量信息（体积膨胀）
- **优势**: 保持椭球形式，允许迭代集成

## 不等式提示（新贡献）

### 定义
- **不等式提示**: ⟨v, s⟩ ≤ l（或 ≥ l）
- **来源**: 解密失败信息——当解密失败时，知道 Δm 超过某阈值，推导出关于 s 的不等式约束
- **几何意义**: 半空间切割椭球

### 与近似提示的区别
| 特性 | 近似提示 | 不等式提示 |
|------|---------|-----------|
| 信息方向 | 双向（等式+噪声） | 单向（不等式约束） |
| 几何运算 | 高斯模糊超平面 | 半空间 |
| 信息量 | 取决于噪声 σ | 取决于约束紧度 |
| 实际来源 | 有噪声值泄漏 | 解密失败 oracle |

## 组合提示（新贡献）

### 定义
- **组合提示**: 融合来自不同信息源的椭球
- 例如: SCA 泄漏（近似提示）+ 解密失败（不等式提示）

### 椭球融合
- 两个椭球 E1, E2 的融合 = 它们定义的约束区域的交集
- 用 Löwner-John 椭球近似交集
- **实际意义**: 允许组合多条侧信道路线的信息

### 应用场景
1. **SCA + DF**: 侧信道泄漏 + 解密失败不等式
2. **多次 SCA**: 不同时间/位置的多次泄漏
3. **SCA + 结构**: 侧信道 + 设计结构信息

## 完美提示重访

### DDGR 原始处理
- 超平面交叉 → 降维
- 但畸变矩阵的处理不够精确

### 几何修正
- 椭球与超平面交叉 → Löwner-John 椭球
- 精确计算交叉后的体积变化
- 修正了 DDGR 的安全估计偏差

## Failure Boosting 几何类比

### 原始 Failure Boosting [DVPL19]
- 利用解密失败的信息，**主动构造**更容易失败的密文
- 每次失败缩小密钥空间

### 几何类比
- 密钥空间 = 椭球
- 每次解密失败 = 椭球与半空间的交叉
- 多次失败 = 椭球不断缩小
- **加速搜索**: 选择最容易触发失败的密文方向

## 非高斯数据处理

### 问题
- DDGR 假设所有噪声为高斯分布
- 实际中 CBD（中心化二项分布）不是严格高斯

### 解决
- 用矩匹配将非高斯分布近似为高斯
- 或用椭球直接表示非高斯支撑集
- 误差分析表明近似质量可接受

## 局限性

1. **椭球近似累积误差**: 每次 Löwner-John 近似都有信息损失
2. **计算复杂度**: 椭球运算在高维下仍然昂贵
3. **不等式提示信息量有限**: 单个不等式约束信息量不如等式提示
4. **未实验验证**: 估计停留在理论层面
